# 编码规范门禁收紧与回归验证

日期：2026-10-31。本轮只收紧现有集成，没有替换工作流，没有修改团队规范原文，也没有操作真实技能安装目录或远程任务。

## 修改

- 共享入口的 Standards Gate 统一定义规范加载、必需验证和完成条件。规范无法读取时停止受影响的代码修改与合规批准；必需检查失败或无法运行时，任务保持未验证、未完成。
- 区分规划、TDD RED 中间阶段、实现交付和只读审查。只读审查可以使用与最终变更一致的验证证据，不能以旧成功日志或缺失证据给出无保留通过。
- 初始化的 AGENTS.md/CLAUDE.md 模板加入 Coding standards 入口，并登记阶段、适用范围、实际命令和证据。
- 快速开始改为一次安装改造版整套技能，消除仍安装原作者版本和需要单独选择若依规范的歧义。

规则定义仅维护在共享入口；各技能链接它，不复制另一份门禁规则。
